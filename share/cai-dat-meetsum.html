Cài đặt trên Windows

Windows sẽ hiện một bảng cảnh báo màu xanh khi bạn mở file cài đặt. Đó là bình thường — không phải app có virus. Dưới đây là chính xác những gì cần bấm.

Bạn cần có

File MeetSum-1.0.0-win-x64.exe (khoảng 114 MB) do bên IT gửi. Máy Windows 10 hoặc 11, 64-bit. Không cần quyền Administrator.

  1. Mở file cài đặt

    Nhấp đúp vào MeetSum-1.0.0-win-x64.exe.

  2. Windows chặn lại — bấm “More info”

    Bảng này hiện ra. Nút duy nhất bạn thấy là Don't run, nên nhiều người dừng ở đây. Chỗ cần bấm là dòng chữ nhỏ More info:

    Màn hình bạn sẽ thấy

    Don't run

    Bấm “More info”, bảng sẽ mở rộng ra và hiện thêm nút Run anyway.

    Vì sao Windows cảnh báo?

    Windows cảnh báo với mọi phần mềm chưa mua chứng chỉ ký số — loại chứng chỉ giá vài trăm đô mỗi năm, dành cho phần mềm bán ra thị trường. MeetSum là công cụ nội bộ nên không mua. Cảnh báo này nói “tôi chưa từng thấy file này”, không phải “file này có hại”.

  3. Chọn thư mục rồi cài

    Giữ nguyên thư mục mặc định và bấm Install. Cài xong bấm Finish — MeetSum tự mở lên, và có sẵn shortcut ngoài Desktop.

  4. Kiểm tra máy đã đủ điều kiện chạy

    Trong MeetSum, bấm biểu tượng bánh răng ở góc phải trên → tab Kiểm tra hệ thống → nút Kiểm tra môi trường.

    Dòng ffmpeg phải xanh — cái đó có sẵn trong app. Các dòng còn lại phụ thuộc bạn chọn cách nào ở phần dưới đây.

Trước khi bóc băng được video đầu tiên

Chọn một trong hai cách

MeetSum không tự nghe được video — nó cần một công cụ nhận dạng giọng nói. Hai lựa chọn, khác nhau ở chỗ dữ liệu cuộc họp có rời khỏi máy bạn hay không.

Cách nhanh
Dùng Gemini API

Dán API key vào Cài đặt → Bóc băng → Qua API. Không phải cài gì thêm, chạy nhanh, tự tách người nói.

Đánh đổi: âm thanh cuộc họp được tải lên máy chủ Google. Đừng dùng cho họp có nội dung nhạy cảm.

Cách kín đáo
Chạy offline bằng Python

Cài Python rồi chạy pip install faster-whisper "pyannote.audio>=3.1" torch torchaudio, thêm một token HuggingFace miễn phí.

Đánh đổi: mất khoảng 15 phút cài lần đầu và chạy chậm hơn. Bù lại không có gì rời khỏi máy bạn.

Phần tóm tắt thì dễ hơn

Nếu máy bạn đã có sẵn Claude Code, Gemini CLI, GitHub Copilot CLI hoặc Codex CLI, chỉ cần chọn nó trong Cài đặt → AI. MeetSum dùng luôn tài khoản bạn đã đăng nhập, không cần API key riêng.

Gặp trục trặc

Không thấy dòng “More info” đâu cả

File đang bị Windows đánh dấu là tải từ Internet. Chuột phải vào file cài đặt → Properties → ở cuối tab General, tick ô Unblock → OK. Rồi mở lại file.

File cài đặt tự biến mất sau khi tải về

Windows Defender đã cách ly nhầm. Mở Windows Security → Virus & threat protection → Protection history → tìm mục MeetSum → Restore.

Nếu không thấy, báo lại người gửi file cho bạn.

Cài xong nhưng app không mở lên

Mở thư mục cài đặt (mặc định C:\Users\<tên bạn>\AppData\Local\Programs\MeetSum) rồi chạy trực tiếp MeetSum.exe.

Bóc băng báo lỗi 401 hoặc GatedRepoError

Bạn đang dùng cách offline nhưng chưa có token HuggingFace. Đăng nhập huggingface.co, bấm Agree and access repository ở cả hai trang pyannote/speaker-diarization-3.1 và pyannote/segmentation-3.0, tạo token loại Read, rồi dán vào Cài đặt → Bóc băng.

Thiếu một trong hai trang là vẫn lỗi — đây là chỗ hay bị bỏ sót nhất.

Muốn cài mà không hiện cảnh báo nào

Xin bên IT file chứng chỉ MaiMoney-CodeSigning.cer kèm script install-signing-cert.ps1, để hai file cạnh nhau, mở Terminal bằng quyền Administrator rồi chạy script một lần. Sau đó mọi bản MeetSum đều hiện publisher là MaiMoney thay vì Unknown.

Dữ liệu cuộc họp nằm ở đâu

Toàn bộ bản bóc băng, tên người nói và bản tóm tắt được lưu dưới dạng file JSON trong %APPDATA%\MeetSum\MeetSumData trên chính máy bạn. Không có máy chủ, không có cơ sở dữ liệu, không đồng bộ đi đâu.

Ngoại lệ duy nhất: nếu bạn chọn bóc băng qua API hoặc tóm tắt bằng AI, phần nội dung đó được gửi tới nhà cung cấp bạn chọn. Gỡ app không xoá thư mục này — muốn xoá sạch thì xoá tay.
